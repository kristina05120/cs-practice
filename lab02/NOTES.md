1\. рабочая папка - текущая папка с файлами, с которыми работаешь.

2\. индекс - изменения, которые хочешь включить в коммит.

3\. коммит - сохранёный снимок изменений репозитория.

различия GIT и GITHUB: git - это программа, которая следит за изменениями файлов, а GitHub - это сайт, куда выкладывают Git - репозитории.



\- git status - показывает состояние рабочей директории и индекса: какие файлы изменены, добавлены или подготовлены к коммиту.

\- git diff - показывает различия между рабочей директорией и индексом.

\- git diff --staged - показывает различия между индексом и последним коммитом.
